最后一步，交给 GitHub。

当前页面不会直接启动编译。请在自己的仓库中按下面的参数运行工作流。

platform
profile
device
  1. 如果还没 Fork，先按新手教程复制项目并启用 Actions。
  2. 打开工作流，点击 Run workflow，分支选择 main。
  3. 填写上面的 platform、profile；如显示 device，也原样填写。不勾选 configure_only。
  4. 点击绿色 Run workflow，等待云端构建。
原有平台按组构建；扩展 ARM 目录使用 custom + device 单机型构建。目录匹配仅代表配置已加入，云端编译与实机测试仍需验证。
